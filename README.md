# networking-labs
Hands-on networking labs built in Cisco Packet Tracer while studying for CCNA. Each lab has the .pkt file, device configs, screenshots, and a write-up of what went wrong and how I fixed it.


## Labs

| Lab | Topic | Skills |
|-----|-------|--------|
| [Lab 01: Static Routing](Lab-01-static-routing/) | Connecting two LANs through three routers | Static routes, default gateway, troubleshooting |

| Lab | Topic | Skills |
|-----|-------|--------|
| [Lab 02: Static Routing with Basic Device Security](Lab-02-static-routing/) | Static routing plus basic router security | Static routes, enable secret, console and VTY passwords, login banner, timezone and clock, troubleshooting |
